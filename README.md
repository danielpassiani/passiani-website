# Passiani Advogados

Código-fonte do website institucional da Passiani Advogados.

## Desenvolvimento

### Requisitos

* Node.js
* npm

### Instalação

```bash
npm install
```

### Executar localmente

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Estrutura principal

```text
public/   Arquivos públicos e assets
src/      Código-fonte da aplicação
```

## Tecnologias

* React
* TypeScript
* Vite
